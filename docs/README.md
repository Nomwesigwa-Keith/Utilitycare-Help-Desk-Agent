# Documentation and Evidence Map

This repository follows the course's recommended GitHub structure. These folders are organised by artefact purpose, not by the week in which an artefact was created.

| Folder | Owns | Current examples |
| --- | --- | --- |
| `requirements/` | Charter, requirements, user stories, acceptance criteria, boundary matrix, model-selection decision | Week 1 and Week 2 documents |
| `architecture/` | Context, architecture, RAG, tool and agent diagrams | Initial architecture diagram |
| `weekly-reports/` | Weekly factual progress reports | Week 1 and Week 2 reports |
| `evaluation/` | Evaluation methodology, failure analysis and written result summaries | Reserved for Week 3 onward |

Generated raw evidence belongs in `../evidence/`, not in this folder. Store trace and result files in `../evidence/traces/`; store screenshots in `../evidence/screenshots/`; store demonstration materials in `../evidence/demo/`.
